## Setup Steps for .in / .com Domain
1. Supabase Project बनवा (supabase.com) -> SQL Editor मध्ये supabase.sql मधला कोड टाका
2. .env.local फाईल मध्ये SUPABASE URL आणि KEY टाका
3. GitHub वर Push करा
4. Vercel वर Import करा -> Deploy
5. Vercel > Settings > Domains मध्ये तुमचा .in / .com domain टाका
